# 术语表

| 术语 | 含义 |
|---|---|
| Agent | 具有目标、上下文、工具和策略的执行单元 |
| Orchestrator | 调度智能体、维护状态、驱动流程 |
| Supervisor | 集中式主智能体——负责规划、路由、综合汇总 |
| Handoff | 一个智能体将对话控制权转移给另一个智能体 |
| Subagent | 由宿主智能体调用的智能体，通常专注于特定领域 |
| Blackboard | 用于共享状态、证据或产物的公共空间 |
| Trace | 智能体执行过程的结构化记录 |
| MCP | Model Context Protocol——连接工具、资源、提示 |
| A2A | Agent2Agent Protocol——智能体间互操作协议 |
| Agent Client Protocol | IDE/客户端到编码智能体的协议 |
| HITL | Human-in-the-loop——人类审批、纠正、决策 |
| Verifier | 用于验证、审查或评分的智能体或工具 |
| Refinement Loop | 迭代式的"生成→评估→修订"循环 |
| MoA | Mixture-of-Agents——分层集成 |
| Stigmergy | 通过环境痕迹实现智能体间间接协作 |
